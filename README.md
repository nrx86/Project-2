# NR86 To-Do App

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and responsive interface
- Interactive animations
- Cricket-inspired visual design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
